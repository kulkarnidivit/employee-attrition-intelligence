# Employee Attrition Intelligence Platform

An end-to-end machine learning project that predicts employee attrition risk,
explains the model's predictions, and supports HR decision-making.

> Status: Phase 0 - project setup (in progress)

## Setup

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

More documentation will be added as the project grows.
